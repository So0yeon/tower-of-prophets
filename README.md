# 예언자들의 탑 (Tower of Prophets)

초등학교 고학년용 심리전·추론 웹게임. <더 지니어스> 스타일의 "평균의 절반 맞히기"(케인스 미인대회) 게임을, 인류 멸망 후 남은 예언 장치라는 세계관으로 풀어냈습니다. 교사는 전자칠판, 학생은 태블릿(디벗)에서 **링크 하나**로 접속합니다.

---

## 1. 가장 빠른 시작 (3단계)

### ① Supabase 프로젝트 만들기 (무료)
1. https://supabase.com 에서 무료 회원가입 → **New project** 생성 (지역은 가까운 곳, 예: Northeast Asia).
2. 프로젝트가 켜지면 좌측 **SQL Editor** → **New query** → 이 저장소의 `schema.sql` 내용을 통째로 붙여넣고 **Run**.
   - 테이블 4개(rooms, players, prophecies, ability_uses), 실시간 publication, 정리 함수까지 한 번에 생성됩니다.
3. 좌측 **Project Settings → API** 에서 두 값을 복사:
   - **Project URL** (예: `https://abcdwxyz.supabase.co`)
   - **anon public** 키 (긴 문자열) — ⚠️ `service_role` 키는 절대 사용하지 마세요.

### ② 설정값 넣기
`js/config.js` 파일을 열고 위에서 복사한 두 값을 붙여넣습니다.

```js
SUPABASE_URL:      "https://abcdwxyz.supabase.co",   // ← 본인 값
SUPABASE_ANON_KEY: "eyJhbGciOi...(긴 키)",            // ← 본인 값
```

### ③ 배포 (링크 하나 만들기)
이 폴더 전체를 정적 호스팅에 올리면 끝입니다. 빌드 과정이 없습니다(순수 HTML/CSS/JS).

- **GitHub Pages**: 저장소에 push → Settings → Pages → 브랜치 지정 → 발급된 주소 사용.
- **Netlify / Vercel**: 폴더를 드래그&드롭하거나 저장소 연결 → 자동 배포.

배포된 주소(예: `https://내사이트/`)가 **교사·학생 공용 링크**입니다. 첫 화면에서 역할(교사/학생)을 고릅니다.

---

## 2. 수업에서 쓰는 법

1. **교사**: 링크 접속 → "교사로 시작" → 자동으로 **4자리 방 코드**가 발급됩니다(교실마다 중복되지 않음). 코드를 전자칠판에 띄웁니다.
2. **학생**: 같은 링크 접속 → "예언자로 입장" → 방 코드 + 닉네임 입력.
3. 전원 입장하면 교사가 **계층 시작**. 학생들은 5분 동안 자유롭게 대화·협상·연합·배신하며 1~100 숫자(예언)를 제출합니다.
4. 전원 제출 또는 타이머 종료 시 **결과 공개 연출** → 진실의 좌표(평균×0.5) 등장 → 상위 5명·획득 통찰력 공개.
5. 5계층 반복 후 누적 통찰력 1위가 **초월자**로 선정됩니다.
6. 교사가 **게임 종료**를 누르면 해당 방의 모든 데이터(예언·능력 기록·방)가 즉시 삭제됩니다.

기본 설정: 5계층 · 계층당 5분 · 결과 1분 · 약 36분. `js/config.js`에서 조정 가능합니다.

### 능력 카드 (3계층부터 해금, 1회 1통찰력)
- **운명의 장막**: 이번 계층 결과에서 내 예언값을 ???로 가림(계산은 정상).
- **정신 감응**: 다른 예언자 1명의 예언값 확인.
- **아카식 열람**: 이전 계층 기록 다시 보기.
- **공명**: 지목한 예언자가 통찰력을 얻으면 나도 같은 양만큼 추가 획득.

---

## 3. 데이터 정책
- 게임은 휘발성입니다. 게임 종료 시 방·예언·능력 기록을 **모두 삭제**합니다(장기 저장 없음).
- 수집 정보는 학생이 입력한 닉네임뿐이며 개인정보(실명·학번 등)는 받지 않도록 안내하세요.
- 종료를 누르지 않고 방치된 방이 쌓이지 않도록 `purge_stale_rooms()` 함수를 제공합니다. Supabase의 **Scheduled Function/cron**으로 하루 1회 실행하면 오래된 방이 자동 정리됩니다.

---

## 4. 보안 안내 (꼭 읽어주세요)
빠른 수업 배포를 위해 데이터베이스 접근 정책(RLS)을 `open_all`(익명 사용자 전체 허용)로 열어 두었습니다. 비영구·비개인정보 게임 데이터에는 충분하지만, 이론적으로는 코드를 아는 사람이 임의로 값을 쓸 수 있습니다. 학급 단위 단발성 수업에는 문제가 없지만, 공개 인터넷에 장기간 노출하거나 더 엄격히 운영하려면 다음을 권장합니다.
- 점수 계산·제출을 **Supabase Edge Function**으로 옮겨 클라이언트의 직접 쓰기를 제한.
- 방 코드에 만료시간을 두고 `purge_stale_rooms()`를 주기 실행.
- RLS 정책을 방 코드·역할 기반으로 좁히기.

## 5. 폴더 구조
```
tower-of-prophets/
├─ index.html        ← 시작 화면(교사/학생 역할 선택)
├─ teacher.html      ← 교사 전자칠판 화면
├─ student.html      ← 학생 태블릿 화면
├─ schema.sql        ← Supabase에 한 번 실행하는 DB 스키마
├─ css/style.css     ← 전체 테마(남색·청록·금색, 유리 패널, 원형 장치)
├─ js/
│  ├─ config.js      ← ★ 여기 Supabase 값만 입력
│  ├─ game-logic.js  ← 순수 계산(평균·진실의 좌표·순위·점수)
│  ├─ db.js          ← Supabase 연동(방/입장/제출/실시간/정리)
│  ├─ teacher.js     ← 교사 화면 로직(게임 진행·타이머·결과 연출)
│  └─ student.js     ← 학생 화면 로직(예언 제출·능력 카드)
├─ assets/           ← (선택) 배경 이미지 — assets/README.md 참고
└─ demo.html         ← Supabase 없이 보는 미리보기(봇 자동 진행)
```

### 미리보기
`demo.html`은 서버 없이 **혼자 둘러보는 데모**입니다. 가짜 예언자(봇)들이 자동으로 숫자를 내고 결과 연출까지 흐름을 재생하므로, 분위기와 진행을 빠르게 확인할 수 있습니다. (실제 수업은 위 1~2단계를 따릅니다.)

---

## 6. 작동 원리(요약)
- 결과 계산은 교사 화면이 담당합니다(별도 서버 함수 없이 배포 단순화). 공개 시 평균→진실의 좌표→거리→순위→통찰력을 계산해 저장하고, 모든 화면이 실시간 구독으로 동기화됩니다.
- 동점은 공동 순위 처리(1위 2명이면 둘 다 +8, 다음은 3위 +3).
- "운명의 장막"은 표시만 가리고 계산에는 그대로 반영, "공명"은 지목 대상이 통찰력을 얻을 때 결과 단계에서 보너스로 합산됩니다.

문제가 생기면 대부분 `js/config.js`의 두 값 또는 `schema.sql` 실행 여부 때문입니다. 브라우저 개발자도구(F12) 콘솔의 메시지를 먼저 확인하세요.
